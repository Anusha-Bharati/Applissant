
# Applissant

A lightweight, open-source Safari and Chrome extension that helps autofill repetitive job application forms using your own saved profile.

No AI. No bulky interface. No automatic application submission.

## Features

- One-click autofill from the Chrome/Safari toolbar.
- Save your personal and professional information.
- Autofill common application fields.
- Support for contact details, location, employment information and application questions.
- Right-to-work information and notice period fields.
- LinkedIn, GitHub and portfolio links.
- Profile information stored locally in your browser.
- Clear your saved profile whenever you want.

### Add the extension to Chrome

1. Open Google Chrome.
2. Navigate to `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted `job-autofill` folder.
6. Pin Job Autofill to your Chrome toolbar.

### Configure your profile

1. Open `chrome://extensions`.
2. Find Job Autofill.
3. Click **Details**.
4. Select **Extension options**.
5. Enter your own personal and professional information.
6. Click **Save my profile**.

### Use the extension

1. Open a supported job application page.
2. Wait for the application form to load.
3. Click the Job Autofill icon in your Chrome toolbar.
4. Review the populated fields.
5. Correct anything that needs attention.
6. Submit the application yourself.

## Privacy

- No AI services or external APIs are used.
- Profile information is stored using Chrome local extension storage.
- Personal information is not included in the source code.
- The extension does not automatically submit applications.
- Users can clear their saved profile from the options page.

Note: Browser-local storage is not encrypted. Only save information you are comfortable storing in your browser profile.

## Compatibility

The extension is designed for Chrome and Chromium-based browsers.

Job application platforms may use different form controls and validation methods. Some fields, dropdowns, radio buttons and multi-step forms may require additional compatibility work.

Ashby compatibility is under development.

## Development

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Edit the extension files.
4. Open `chrome://extensions`.
5. Click Reload after making changes.
6. Test on a job application form.
